# **App Name**: EditClean

## Core Features:

- Interactive Image Upload: Implement a user-friendly drag-and-drop interface for image uploads. Users can click on a designated frame to trigger the upload or drag images directly into it.
- Background Remove: Automatically remove the background from the uploaded image, providing a clean product image.
- AI Background Generator Tool: Generate AI Custom Background: allow users to create unique and relevant backgrounds. The LLM will use reasoning to decide when or if to incorporate some piece of information in its output. Therefore, this is a tool.
- AI Color Background: AI Color Background: allow users to automatically find and apply eye-catching colors.
- Resize & Crop Presets: Offer a range of preset sizes and crop ratios tailored for various e-commerce platforms like Tokopedia and Shopee, Instagram, and Facebook, along with custom pixel resizing options.
- Ad Logic: Implement interstitial ads that appear before processing each edit for non-premium users.
- Premium Page: Create a dedicated premium subscription page outlining the benefits of upgrading, such as high-resolution downloads, batch processing, and custom background options.
- Login/Register with Firebase Auth: Implement user authentication with Firebase Auth, providing login and registration functionality.
- Checkout Page: Use Stripe for card payments and Apple/Google Pay. Add PayPal as a second option. Display prices in USD. Use a PCI-compliant checkout page (e.g., Stripe Checkout) to avoid handling card data.
- Policy Page: A page to display the Privacy Policy and Terms of Service for the app
- Blog Page: A page containing articles about our service, for marketing and SEO
- Contact Page: A page for users to contact the app support team.
- Adsense Integration: Add Adsense sections to the left and right sides of the page for monetization.

## Style Guidelines:

- Latar belakang: #121212 (hitam keabu-abuan)
- Teks utama: #ffffff (putih)
- Aksen: #00BCD4 (cyan)
- Warna sekunder: #1f1f1f (abu tua)
- Body and headline font: 'PT Sans' (sans-serif) due to its mix of modern design and approachability. This will make the app's text more appealing to users in the UMKM sector.
- Use clear and minimalist icons for upload, editing, and export functions.
- Employ a clean, card-based layout for presenting editing options and image previews.
- Incorporate subtle transitions and loading animations to enhance user experience during image processing.
- Base the UI components on Shadcn UI for a modern and consistent design system.
